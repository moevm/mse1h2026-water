# mse-template

## Установка и запуск
Инструкции по установке и запуску проекта.
  
To install all dependences in project just type in project directory:
```
pip install -r requirements.txt
```
    
  
To start Web App you can type in terminal in project folder ("MSE1H2026-WATER")
```
python -X utf8 -m streamlit run streamlit_app.py --server.port 8501
```
